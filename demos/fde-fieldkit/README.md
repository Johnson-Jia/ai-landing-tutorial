# FDE 现场四件套

FDE（Forward Deployed Engineer）进客户现场的四件套——**需求探索画布** + **PoC→生产清单** + **能力自评矩阵** + **客户干系人地图**。

对应教程：[番外·FDE 篇](../../pages/fde.html)（视角：乙方客户现场，区别于主教程的甲方内部转型）

## 清单

| 资产 | 用途 | 何时用 |
|---|---|---|
| [01-需求探索画布](./01-fde-discovery-canvas.md) | 进现场摸清业务、定位 AI 发力点 | 首次客户访谈、需求探索阶段 |
| [02-PoC→生产清单](./02-poc-to-prod-checklist.md) | 把演示变成客户真在跑的系统 | PoC 验证完、准备上生产前 |
| [03-能力自评矩阵](./03-fde-skill-matrix.md) | 自评 FDE 能力、找缺口、排补缺 | 想转 FDE / 规划成长时 |
| [04-客户干系人地图](./04-stakeholder-map.md) | 识别受益/受损方、找 champion、摸决策链 | 进场第一周、项目全程更新 |

## 使用方式

- **探索画布**：带着做客户访谈，边问边填，填完和客户对齐发力点与价值假设。
- **PoC→生产清单**：扩生产前逐组打勾，任一组没过别上线。
- **能力矩阵**：逐项自评打分，照「补缺路径」学，攒作品。
- **干系人地图**：进场第一周就填，识别受益/受损方与拍板人，全程更新。
